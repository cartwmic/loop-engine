# Fictional repository README

`fictional-repo` coordinates externally performed software changes through durable workflow states. The provider is a fresh process per request: it exposes frozen policies and schemas, checks contained authored artifacts, and evaluates supplied external evidence without judging semantic truth. The engine owns workflow progression; no provider call routes or persists workflow state.
