# Target authoring guidance

README profile provides deterministic floors for project H1 title, purpose, onboarding, usage, validation, commands in onboarding and validation sections, and resolvable local references. AGENTS profile provides scope/authority, executable workflow/validation, completion/handoff, workflow command, and resolvable local references; it does not require title or fixed heading spelling. Semantic axes require external review against the repository tree, not the document alone; they do not add Architecture, Gotchas, persona, or completeness headings. Keep local references relative to target parent. Provider reads bytes once per evaluation, computes lowercase SHA-256, and does not lock target across engine commit.
