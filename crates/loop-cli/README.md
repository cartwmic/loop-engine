# loop-engine

`loop-engine` is Loop Engine's durable workflow CLI. It stores run state in SQLite and coordinates external provider executables; agents perform primary work outside the engine.

For command forms, JSON outcomes, and the agent handoff loop, read [`docs/agent-usage.md`](../../docs/agent-usage.md). For prebuilt releases and source installation, read the repository [Install section](../../README.md#install).
